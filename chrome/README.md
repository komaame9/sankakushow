この拡張機能をChromeにインストールする手順は、主に**ファイルの準備**と**デベロッパーモードでの読み込み**の2つのステップになります。


### 1\. Chromeで拡張機能を読み込む

準備したフォルダをChromeの「**デベロッパーモード**」を使って読み込みます。

1.  **Chromeで拡張機能の管理画面を開く**

      * アドレスバーに `chrome://extensions` と入力して移動します。
      * または、右上のメニュー（縦の3点リーダー） \> **[拡張機能]** \> **[拡張機能を管理]** を選択します。

2.  **デベロッパーモードを有効にする**

      * 画面右上の **[デベロッパーモード]** のトグルスイッチをオン（青色）にします。

3.  **拡張機能を読み込む**

      * 画面左上の **[パッケージ化されていない拡張機能を読み込む]** ボタンをクリックします。
      * ステップ1で作成したフォルダ（例: `image_url_sender`）を選択し、**[選択]** をクリックします。

これで、拡張機能がChromeにインストールされ、すぐに使用可能な状態になります。

### 3\. 動作確認

ウェブページ上の**画像**を右クリックすると、コンテキストメニューに「**画像の情報を取得 (REST GET)**」という項目が追加されていることを確認できます。

  * クリックすると、`service_worker.js` 内に設定したAPIエンドポイントにGETリクエストが送信されます。
  * 結果はブラウザの通知として表示され、詳細なログ（成功/失敗）は、拡張機能の管理画面から **[サービスワーカー]** のリンクをクリックして開く**デベロッパーツール**のコンソールで確認できます。
